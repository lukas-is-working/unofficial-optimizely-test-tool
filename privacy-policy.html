Privacy Policy

Effective date: October 25, 2026

The Unofficial Optimizely Test Tool is an independent community project and is not affiliated with, endorsed by, or sponsored by Optimizely.

Data processed

When the related features are used, the extension processes a personal Optimizely API token, Optimizely runtime data, experiment metadata, events, selected testing cookies, URLs and event payloads.

Use and storage

  • The API token is stored locally in Chrome and sent only to https://api.optimizely.com for user-triggered validation and metadata requests.
  • Page data, cookies, experiments and event logs are processed locally.
  • The extension does not sell data, use it for advertising, or send it to an analytics service.
  • QR codes are generated locally. Users should treat Optimizely-generated share links as sensitive.

Retention and deletion

The token and settings remain in the Chrome profile until removed in Settings or the extension is removed. Event logs are kept in Chrome extension storage while the related tab is open and may optionally be preserved across reloads when the user enables that setting. They can be cleared from the popup.

Third parties

Optimizely receives API requests when the user configures a token and uses API-backed features. The user may also explicitly copy or open Optimizely-generated share links, including through a locally generated QR code. No other remote backend is operated by this project.

Contact

For questions or issue reports, use the repository's GitHub Issues.
